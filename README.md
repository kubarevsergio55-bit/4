# Практическая работа: Инкапсуляция в C#

**Выполнил:** Кубарев Сергей

## Классы проекта
- **Supplier**: валидация названия, телефона и ИНН (10/12 цифр).
- **Product**: инкапсуляция полей, контроль MinStock, привязка поставщика, вычисляемые свойства (TotalPrice, IsBelowMinStock) и метод списания WriteOff.
- **Warehouse**: защита коллекции (возврат копий), удаление позиций Remove, отчёт по дефициту, журнал операций GetHistory и атомарное перемещение Transfer.
